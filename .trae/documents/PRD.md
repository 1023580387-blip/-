# PRD - NEON//PULSE 霓虹赛博风着陆页

## 1. 产品概述

NEON//PULSE 是一个虚构的赛博朋克数字地下创意平台着陆页，定位为"霓虹脉冲"——一个面向设计师、开发者与赛博文化爱好者的创意集体。
- **核心目的**：以高视觉冲击力的霓虹赛博风格呈现品牌形象，吸引目标用户加入集体并申请早期访问
- **目标用户**：追求未来感美学的数字创作者、独立开发者、赛博朋克文化爱好者
- **市场价值**：作为 MotionSites 霓虹赛博风模板的标杆案例，展示故障动画 / 网格背景 / 霓虹辉光等动效的极致表现力

## 2. 核心功能

### 2.1 用户角色
| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 访客 | 直接访问 | 浏览所有内容区块，体验动效交互 |
| 申请者 | 点击 CTA | 提交早期访问申请（模拟表单） |

### 2.2 功能模块
1. **单页着陆页**：单页面包含 Hero、协议特性、数据脉冲、宣言、加入 CTA、底部信息

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 着陆页 | Hero 区 | 故障文字标题、透视网格背景、霓虹辉光、CTA 按钮、悬浮几何体 |
| 着陆页 | 协议特性 | 3 张悬浮脉冲卡片，hover 时霓虹边框激活，展示协议核心能力 |
| 着陆页 | 数据脉冲 | 实时滚动数据条 / 终端日志流，营造"活着的系统"感 |
| 着陆页 | 宣言区 | 大字排版宣言，逐行滚动揭示，背景扫描线 |
| 着陆页 | 加入 CTA | 申请表单（昵称 + 频道），提交后显示赛博风确认态 |
| 着陆页 | 底部 | 站点地图、社交链接、版权信息、霓虹分隔线 |

## 3. 核心流程

## 4. 用户界面设计

### 4.1 设计风格
- **主色**：深黑 `#050208`（背景）+ 纯黑 `#0a0a0f`（卡片）
- **霓虹强调色**：热粉 `#ff006e`、电青 `#00f0ff`、酸绿 `#c6ff00`、紫品红 `#b026ff`
- **按钮风格**：透明背景 + 霓虹边框 + 辉光阴影，hover 时边框扫光、内部填色脉冲
- **字体**：标题用 `Audiowide`（赛博未来感显示字体），正文用 `Space Mono`（等宽科技感），数据用 `JetBrains Mono`
- **布局风格**：单栏纵向滚动 + 不对称网格，区块间用霓虹分隔线
- **图标风格**：lucide-react 线性图标，霓虹色描边
- **氛围细节**：CRT 扫描线叠加、噪点纹理、透视网格地面、悬浮几何体、故障 RGB 偏移

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 着陆页 | Hero 区 | 透视网格背景、故障大标题"NEON//PULSE"、霓虹副标题、双 CTA 按钮、悬浮几何体、扫描线 |
| 着陆页 | 协议特性 | 3 张卡片网格，每张含图标 + 标题 + 描述，hover 霓虹边框脉冲 |
| 着陆页 | 数据脉冲 | 终端日志流 + 滚动数字指标，等宽字体，绿色光标闪烁 |
| 着陆页 | 宣言区 | 巨幅宣言文本逐行揭示，左右不对称排版，背景扫描线 |
| 着陆页 | 加入 CTA | 居中表单，霓虹输入框，提交按钮带扫光动画 |
| 着陆页 | 底部 | 多列链接 + 社交图标 + 版权，顶部霓虹分隔线 |

### 4.3 响应式
- 桌面优先设计（1280px+ 完整体验）
- 平板（768-1280px）：网格降列、字号缩减
- 移动端（<768px）：单列堆叠、Hero 字号自适应、关闭部分重型动效以保证性能

### 4.4 动效指引
- **页面加载**：故障标题 RGB 偏移 + 扫描线入场，staggered reveal
- **滚动触发**：IntersectionObserver 触发淡入上移、宣言逐行揭示
- **悬浮交互**：卡片边框扫光、按钮内部脉冲、霓虹辉光增强
- **持续氛围**：网格地面缓动、几何体浮动、终端光标闪烁、扫描线常驻

## 5. 非功能需求
- 性能：首屏 LCP < 2.5s，动效使用 CSS / transform 为主，避免重排
- 可访问性：语义化 HTML、对比度达标、尊重 `prefers-reduced-motion`
- 浏览器兼容：现代 Chromium / Firefox / Safari 最新版
