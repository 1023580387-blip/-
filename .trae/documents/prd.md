# 潮流服饰品牌电商网站 PRD

## 1. 产品概述
潮流服饰品牌展示型电商网站，展示品牌商品并提供购物体验，面向街头潮流文化爱好者。
- 这是一个纯前端展示项目，包含5个主要页面，使用HTML/CSS/JavaScript构建。

## 2. 需求分析

### 2.1 用户需求
- 用户可以浏览品牌商品，查看商品详情
- 用户可以将商品添加到购物车
- 用户可以在购物车中查看已选商品
- 用户可以了解品牌故事

### 2.2 功能需求

#### 页面结构
| 页面 | 功能描述 |
|------|----------|
| 首页 | 品牌展示，轮播Banner，热门商品推荐，品牌理念 |
| 商品列表 | 展示所有商品，支持商品卡片预览 |
| 商品详情 | 展示商品详细信息，图片画廊，加入购物车功能 |
| 关于品牌 | 品牌故事，品牌文化介绍 |
| 购物车 | 查看已添加商品，侧边抽屉式设计 |

#### 核心交互功能
- **首页轮播Banner**: 自动播放 + 手动切换按钮
- **商品卡片悬停效果**: 第二张图淡入切换 + 快速购买按钮滑入
- **商品详情图片画廊**: 点击缩略图切换主图
- **购物车侧边抽屉**: 从右侧滑入展示
- **加入购物车动画**: 抛物线飞入动画效果
- **下拉菜单**: 缓动展开动画
- **导航栏购物车角标**: 实时显示购物车商品数量

### 2.3 设计风格
- **风格定位**: 街头潮流风，大胆排版
- **配色方案**: 黑白为主色调 + 高饱和红色作为点缀色
- **设计语言**: 硬朗、冲击力强、不对称排版

## 3. 设计系统

### 3.1 色彩规范
- **主色**: `#000000` (黑色背景)、`#FFFFFF` (白色文字)
- **点缀色**: `#FF3333` (高饱和红色)
- **中性色**: `#1A1A1A`、`#333333`、`#CCCCCC`、`#F5F5F5`

### 3.2 字体规范
- **标题字体**: 无衬线粗体 (如 Oswald)
- **正文字体**: 无衬线清晰字体 (如 Inter)
- **排版**: 大标题冲击感，强烈对比字号

### 3.3 动画效果
- 轮播Banner: 淡入淡出切换，3秒自动轮播
- 商品卡片悬停: 0.3s缓动过渡
- 购物车抽屉: 0.5s滑入动画
- 抛物线动画: 使用CSS + JS实现贝塞尔曲线运动

## 4. 数据结构

### 商品数据结构
```javascript
{
  id: number,
  name: string,
  price: number,
  description: string,
  category: string,
  images: [string, string], // 主图 + 第二张图(悬停显示)
  gallery: string[], // 详情页画廊图片
  sizes: string[],
  colors: string[],
  featured: boolean
}
```

### 购物车数据结构
```javascript
{
  items: [{
    productId: number,
    quantity: number,
    size: string,
    color: string
  }],
  total: number,
  count: number
}
```
