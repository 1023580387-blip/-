概览

CloudFlow 是一款企业级智能运营平台，集成了数据分析、自动化工作流、团队协作等核心功能。本帮助文档将引导您快速上手并深入使用 CloudFlow 的各项功能。

提示：如果您是第一次使用 CloudFlow，建议从「快速入门」章节开始，10 分钟即可完成基本配置。

平台架构

CloudFlow 采用微服务架构，由以下核心服务组成：

  • 数据引擎 — 实时数据处理与分析，支持 PB 级数据查询
  • 工作流引擎 — 可视化流程编排，支持条件分支与并行执行
  • 协作服务 — 即时通讯、文档协作、项目管理
  • 集成网关 — API 管理与第三方应用集成
  • 安全中心 — 统一认证、权限管理与审计日志

支持平台

  • Web 端：Chrome 90+、Firefox 90+、Safari 15+、Edge 90+
  • 桌面端：macOS 12+、Windows 10/11
  • 移动端：iOS 15+、Android 12+

快速入门

通过以下步骤，您可以在几分钟内完成 CloudFlow 的基础配置，开始使用核心功能。

第一步：创建团队

注册账号后，系统会引导您创建第一个团队。输入团队名称，选择行业类型，系统将自动推荐适合的模板配置。

第二步：邀请成员

通过邮箱邀请团队成员加入。您可以为每位成员设置不同的角色权限：

  • 管理员 — 拥有全部管理权限，可修改团队设置
  • 编辑者 — 可创建和编辑内容，管理项目
  • 查看者 — 只读权限，可查看数据和报表

第三步：连接数据源

CloudFlow 支持多种数据源接入方式。以 MySQL 为例：

# 在平台设置中添加数据源 POST /api/v1/datasources Content-Type: application/json { "type": "mysql", "host": "db.example.com", "port": 3306, "database": "analytics" }

第四步：创建首个看板

进入「数据看板」模块，点击「新建看板」，选择数据源和可视化图表类型，拖拽即可完成配置。

安装与配置

CloudFlow 提供云端 SaaS 和私有化部署两种方式。本节介绍私有化部署的基本流程。

系统要求

  • 操作系统：Linux (Ubuntu 20.04+ / CentOS 8+)
  • CPU：4 核及以上
  • 内存：16 GB 及以上
  • 磁盘：100 GB SSD 及以上
  • Docker 20.10+ 与 Docker Compose 2.0+

Docker 部署

使用 Docker Compose 一键部署：

# 下载部署包 wget https://releases.cloudflow.io/latest/docker-compose.yml # 配置环境变量 cp .env.example .env # 编辑 .env 文件，设置数据库密码等参数 # 启动服务 docker compose up -d # 验证服务状态 docker compose ps

初始化配置

服务启动后，访问 http://your-server:8080/setup 进入初始化向导，设置管理员账号和企业信息。完成后即可正常使用。

数据看板

数据看板是 CloudFlow 的核心功能之一，提供实时数据可视化和分析能力。

创建看板

在左侧导航栏点击「数据看板」→「新建看板」，选择空白看板或从模板创建。CloudFlow 提供 20+ 行业模板，涵盖电商、SaaS、金融等场景。

图表类型

  • 折线图 — 展示趋势变化，支持多指标对比
  • 柱状图 — 分类对比，支持堆叠和分组
  • 饼图/环形图 — 占比分析
  • 表格 — 明细数据展示，支持排序和筛选
  • 数字卡片 — 关键指标突出显示
  • 地图 — 地域分布可视化

数据筛选与下钻

每个图表支持全局筛选器联动。点击图表中的数据点可下钻查看明细数据。筛选条件包括时间范围、维度过滤、自定义 SQL 筛选等。

最佳实践：建议为每个业务场景创建独立的看板，避免单个看板图表过多导致加载缓慢。关键指标建议使用数字卡片置顶展示。

自动化工作流

自动化工作流引擎帮助您将重复性任务自动化，提高团队效率。

工作流组成

每个工作流由以下元素组成：

  • 触发器 — 定义工作流启动条件（定时、事件、Webhook 等）
  • 条件 — 分支逻辑判断，支持 AND/OR 组合
  • 动作 — 具体执行的操作（发送通知、更新数据、调用 API 等）

示例：新用户欢迎流程

触发器：用户注册成功事件 ↓ 条件：用户邮箱域名是否为 @enterprise.com ↓ (是) ↓ (否) 动作：分配企业客户标签 动作：发送标准欢迎邮件 ↓ 动作：通知销售团队跟进

预置模板

CloudFlow 提供 100+ 预置工作流模板，涵盖 CRM、营销自动化、工单管理等场景，一键启用即可使用。

团队协作

团队协作中心集成了即时通讯、文档协作和项目管理功能，帮助团队高效沟通。

频道管理

支持创建公开频道和私密频道。公开频道对团队所有成员可见，私密频道仅限受邀成员访问。建议按项目或部门创建独立频道。

文档协作

内置在线文档编辑器，支持多人实时协同编辑、评论、版本历史。文档支持 Markdown 语法，可嵌入数据看板图表和工作流状态。

文件共享

支持拖拽上传文件，单个文件最大 2 GB（专业版及以上）。文件自动存入团队知识库，支持全文搜索和标签分类。

API 认证

CloudFlow API 使用 API Key 进行身份认证。所有 API 请求必须通过 HTTPS 发送。

获取 API Key

进入「设置」→「开发者」→「API Keys」，点击「创建密钥」。请妥善保管密钥，创建后仅显示一次。

请求认证

在请求头中携带 API Key：

Authorization: Bearer cf_sk_live_xxxxxxxxxxxxxxxxxxxx

权限范围

API Key 支持细粒度权限控制。创建时可选择授予的权限范围（读/写/管理），以及允许访问的资源（看板、工作流、用户等）。

API 接口列表

CloudFlow RESTful API 基础地址：https://api.cloudflow.io/v1

核心接口

方法 路径 说明
GET/dashboards获取看板列表
POST/dashboards创建新看板
GET/workflows获取工作流列表
POST/workflows/:id/trigger手动触发工作流
GET/users获取团队成员列表
POST/users/invite邀请新成员

完整的 API 文档请访问 开发者门户。

API 错误码

CloudFlow API 使用标准 HTTP 状态码。出错时返回 JSON 格式的错误信息。

常见错误码

状态码 说明
400请求参数错误
401未认证或 API Key 无效
403权限不足
404资源不存在
429请求频率超限
500服务器内部错误

错误响应格式

{ "error": { "code": "invalid_parameter", "message": "参数 'name' 不能为空", "details": { "field": "name", "reason": "required" } } }

账号设置

在「设置」→「账号」页面，您可以管理个人信息和安全设置。

个人资料

支持修改头像、昵称、职位、联系方式等信息。头像建议使用 400×400 像素的方形图片。

通知偏好

自定义通知渠道和频率：

  • 产品内通知 — 平台右上角通知中心
  • 邮件通知 — 日报、周报、告警通知
  • 企业微信/钉钉/飞书 — 即时消息推送

计费与发票

在「设置」→「计费」页面，您可以查看当前套餐、用量统计和账单历史。

套餐变更

升级套餐即时生效，费用按剩余天数比例计算。降级在当前计费周期结束后生效，期间可继续使用当前套餐的全部功能。

发票管理

支持开具增值税普通发票和专用发票。在「计费」→「发票」页面填写开票信息，电子发票将在 3 个工作日内发送至您的邮箱。

注意：年付方案支持对公转账。如需对公转账，请联系销售团队获取对公账户信息。

安全设置

CloudFlow 提供多层次安全防护，确保您的数据安全。

双因素认证 (2FA)

建议所有管理员账号启用双因素认证。支持 TOTP 验证器应用（如 Google Authenticator、Authy）和短信验证码。

登录记录

在「设置」→「安全」→「登录记录」页面，可查看最近 30 天的登录历史，包括登录时间、IP 地址、设备信息。如发现异常登录，可立即强制下线。

IP 白名单

企业版支持 IP 白名单功能，限制仅允许指定 IP 地址段访问，进一步增强安全性。
